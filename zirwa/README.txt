ZIRWA CLOTHING STORE - static website
=====================================
Upload every file in this folder to your hosting (public_html) or drag the folder to Netlify / Vercel / Cloudflare Pages.
Then open index.html. No build step needed.

Edit in script.js (top of file):
  STORE   - phone, WhatsApp number, address, shipping threshold and fee
  SOCIAL  - your real Facebook / Instagram / TikTok links
  REVIEWS - add your real customer reviews: { name:'Name', text:'...', stars:5 }
  SPEC    - product names and prices (54 products are generated from this list)

Product pictures are illustrated placeholders. To use real photos, replace the art(...) calls
in card(), initProduct() and initCart() with <img src="images/your-photo.jpg"> tags.

Domain: replace https://zirwa.pk in each page's <link rel="canonical">, sitemap.xml and robots.txt if you use another domain.
Orders: the checkout sends the order to WhatsApp +92 331 7756688 (no online card gateway is built in).
Policies page text is a draft - adjust it to your real shipping times and return rules.
